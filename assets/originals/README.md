# Оригиналы скриншотов

Здесь лежат исходные 2400x1080 JPEG (около 12 MB суммарно) без сжатия.

Рабочие копии, которые отдаются сайтом, лежат в `public/images/one.jpg ... eight.jpg`
(~1920 px по ширине, q80, около 1.4 MB на все 8 фото).

Если нужно заменить фото: положите оригинал сюда, сожмите в `public/images`,
сохранив имя (`one.jpg` ... `eight.jpg`) - код сайта ссылается именно на эти имена.
