# Building Zone - сайт Minecraft-сервера

Одностраничный сайт сервера **Building Zone** (Minecraft Bedrock): воксельный фон на canvas,
бегущая строка, статистика, галерея построек, терминал с данными для подключения и благодарности.

Стек: TypeScript + Vite 7 (`vite-plugin-singlefile` собирает всё в один `index.html`).
Без фреймворка и UI-библиотек - страница собирается один раз и оживляется нативными модулями.

## Подключение к серверу

| Что | Значение |
| --- | --- |
| Адрес | `play.buildzone.lol` |
| Порт | `25903` |
| Полный адрес | `play.buildzone.lol:25903` |
| Версия | Minecraft Bedrock 1.21.50-51 |
| Сайт | https://buildzone.lol |
| Telegram | https://t.me/buildingzone_cube |

Все эти данные лежат в одном месте - `src/data.ts` (объект `SITE`). Меняете адрес/порт/версию
только там: терминал, подпись в hero, футер и SITE-метаданные подтянутся сами.
Строка `ADD_SERVER_LINK` - это deep-link `minecraft://?addExternalServer=...`, по клику на
адрес в терминале сервер сам добавляется в список серверов Bedrock.

## Запуск

```bash
npm install
npm run dev        # разработка
npm run build      # сборка в dist/
npm run preview    # посмотреть собранную версию
npm run typecheck  # проверка типов
```

## Структура

```
index.html                 точка входа (+ мета-теги, preload шрифтов и первого слайда)
src/main.ts                загрузка стилей и запуск приложения
src/app.ts                 сборка страницы, прелоадер, копирование адреса, запуск эффектов
src/data.ts                ВСЁ содержимое: адрес сервера, тексты, список фото, цифры
src/markup.ts              разметка страницы (те же классы/структура, что и раньше)
src/voxels.ts              воксельное поле в hero на canvas
src/gallery.ts             галерея: автоплей, точки, свайпы, ленивая догрузка слайдов
src/effects.ts             курсор, магнитные кнопки, прожектор, reveal, счётчики, прогресс скролла
src/index.css              все стили + локальные @font-face + пауза анимаций вне экрана
public/images/*.jpg|webp   фото галереи (одно и то же фото в двух форматах)
public/fonts/*.woff2       шрифты Unbounded / Golos Text / JetBrains Mono (самохостинг)
public/favicon.svg         иконка сайта
public/_headers            кеширование для Cloudflare Pages
assets/originals/          исходные скриншоты 2400x1080 без сжатия
```

## Галерея

В галерее 8 слайдов. Каждый слайд - это пара файлов с одинаковым именем:
`public/images/one.webp` + `public/images/one.jpg`, `two`, `three` ... `eight`.
Имя файла = порядок слайда, поэтому имена менять нельзя.

Как страница выбирает формат: современные браузеры берут `.webp` (в 2 раза легче),
остальные - `.jpg`. Именно поэтому старый `.jpg` удалять нельзя: это запасной вариант.

Что важно при замене фото:

- кладите обе версии: `name.webp` (основная) и `name.jpg` (фолбэк), имена строго `one` ... `eight`;
- держите вес в разумных пределах: 1920 px по ширине, WebP q72 (~100 KB на фото) и JPEG q80;
- оригиналы складывайте в `assets/originals/`, а в `public/images/` - сжатые версии.

## Что было оптимизировано

- **Скрипт**: 239.8 kB -> ~54 kB (gzip 73.9 kB -> 15.3 kB). React и Tailwind из проекта убраны:
  они попадали в бандл, но ни один их класс/хук на странице не использовался.
- **Фото**: 1.4 MB -> 760 KB (WebP q72), при этом исходные JPEG остались как фолбэк.
- **Шрифты**: Google Fonts заменены на самохостинг (16 файлов, ~256 KB, только latin + cyrillic,
  `font-display: block` для дисплейного шрифта). Нет запросов к fonts.googleapis/gstatic, страница
  не зависит от их доступности, а нужные начертания грузятся сразу (preload).
- **Загрузка картинок**: слайды грузятся по мере надобности (первый - сразу, следующий - заранее),
  вместо восьми фото на старте. Фото «о сервере» тоже ленивое.
- **Процессор/батарея**: анимации (орбиты, бегущая строка, блик CTA, пульсация) ставятся на паузу,
  когда блок вне экрана или вкладка в фоне; canvas не рисуется, когда hero не виден (было и раньше).
- **Метаданные**: title/description/canonical/OG-теги, favicon, `_headers` с кешированием для
  Cloudflare Pages.

Вёрстка при этом не менялась: тот же DOM, те же классы и CSS, та же сетка и отступы.

## Проверка, что все слайды на месте

Любая из команд должна показать по 8 файлов каждого формата:

```bash
ls public/images | grep -c jpg    # 8
ls public/images | grep -c webp   # 8
curl -s -o /dev/null -w "%{http_code}\n" http://localhost:5173/images/one.webp  # 200
curl -s -o /dev/null -w "%{http_code}\n" http://localhost:5173/images/one.jpg   # 200
```
